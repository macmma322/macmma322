### Hi, I'm Nikolay 👋

I'm a software engineer from Devnya, near Varna, Bulgaria. By day I'm a backend
developer at **DXC Technology**, working on an enterprise insurance platform.
The rest of my time goes into building whole systems of my own: production web
platforms, local-first AI, embedded hardware and an operating system written
from scratch.

I like being able to point at the proof. Every claim on my site links to code,
tests or a measurement, and every project states its real status.

## Public repositories

- [**malrynth**](https://github.com/macmma322/malrynth): an x86-64 operating
  system written from scratch in Rust. It has its own UEFI loader, a
  dependency-free kernel that owns physical memory, and CI that boot-tests it
  under QEMU and OVMF.
- [**engineering-blueprint**](https://github.com/macmma322/engineering-blueprint):
  a portable `CLAUDE.md` with the engineering rules I give AI coding agents (MIT).
- [**nikolay-georgiev.dev**](https://github.com/macmma322/nikolay-georgiev.dev):
  the source of my portfolio. It's a static Astro and TypeScript site in English
  and Bulgarian, with a CV that builds itself and an AI-assisted inbox behind
  deterministic guardrails.
